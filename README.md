## 📌 Project Overview

**Explainable Financial Market Analysis using Natural Language Processing** is a system designed to bridge the gap between complex technical chart patterns and human understanding. Instead of acting as a black-box trading bot or giving direct buy/sell calls, this project focuses on **explainability and interpretation**.

### Key Features:
- **Signal Interpretation:** Automatically identifies technical indicators and market signals from structured market data.
- **Natural Language Explanations:** Translates complex technical patterns into concise, easy-to-understand explanations.
- **Interactive Queries:** Allows users to ask natural language questions about the generated market analysis.
- **Transparent & Explainable:** Focuses on *why* a signal matters and how multiple indicators interact with each other.
